Проведи полную проверку проекта перед коммитом. Ничего не исправляй сам,
только проверь и отчитайся (исправления — после ответа пользователя).

Выполни шаги по порядку, каждый — даже если предыдущий упал.

## 1. Анализ кода
`flutter analyze lib test` — сколько ошибок / предупреждений / подсказок.

## 2. Тесты
Если в `test/` есть файлы `*_test.dart` — `flutter test`, итог: сколько прошло и упало.
Если тестов нет — так и написать: «тестов нет».

## 3. Веб-сборка
`flutter build web --release --base-href /hey-helpy/` — только проверка, что собирается.
Ключи Supabase не нужны (без `--dart-define` приложение собирается, просто не подключится к базе).
При ошибке — первые строки ошибки.

## 4. Строки интерфейса вне файлов перевода
Все строки интерфейса должны идти через `lib/l10n/*.arb` (`context.l10n.ключ`).
Ищи в `lib/**/*.dart`, **кроме** `lib/l10n/`:
- кириллицу внутри строковых литералов `'…'` и `"…"`;
- английские фразы в литералах: два и больше слов с буквами, либо слово с заглавной
  буквы, похожее на подпись (`'Save'`, `"Sign in"`), в `Text(...)`, `label:`, `hintText:`,
  `title:`, `tooltip:`, `SnackBar`, `throw`/сообщениях для пользователя.

Не считать ошибкой: комментарии (`//`, `///`), импорты, ключи и коды (`'on_review'`,
`'high'`, имена таблиц, колонок, маршрутов `'/login'`), строки в `debugPrint`/`log`,
форматы дат, имена пакетов. Если сомневаешься — пометь «проверить», а не «ошибка».

## 5. Название продукта
В интерфейсе допустимо только «Эй, Helpy» (RU) и «Hey Helpy» (EN), и только из ключа
`appName` в `lib/l10n/*.arb`.
- Ошибка: «Helpy» без «Эй, » / «Hey » в строковых литералах `lib/` вне `lib/l10n/`,
  а также в значениях `.arb` (кроме фразы активации `wakePhrase`: «Эй, Хелпи» / «Hey, Helpy»).
- Не ошибка: имена классов и идентификаторы (`HeyHelpyApp`, `HeyHelpyTheme`), комментарии.
- Проверь также подписи под иконкой: `android/app/src/main/res/values*/strings.xml`.

## Итог
Короткий список в таком виде (по-русски, просто):

```
✅ Анализ кода — без ошибок
❌ Тесты — 2 упали: <название>
✅ Веб-сборка — собирается
⚠️ Строки вне переводов — 3 места:
   - lib/…/file.dart:31 — "…"
✅ Название продукта — нарушений нет

Что исправить:
1. …
```

В конце спроси, исправить ли найденное.
