## Что проверить

1. Открыть PR → вкладка **Files changed** → папка `docs/screens/latest/` — посмотреть скриншоты прямо в браузере.
2. После merge: вкладка **Actions** → «Build Android APK» — должны пройти обе задачи (`build` и `release`).
3. Через 5–10 минут после merge открыть на телефоне
   https://github.com/Anton-Key/hey-helpy/releases/download/latest-apk/hey-helpy.apk — скачается APK, установить.
4. Завести с телефона тестовую задачу (приложение GitHub → Issues → New, метка `idea`) — в начале шага 10 она
   появится в списке.

## Ограничения

- Релиз `latest-apk` помечен как предварительный (pre-release), чтобы не выглядеть «официальной версией»;
  ссылка от этого не меняется. Первый раз он появится только после merge этого PR в `main`.
- Экран «Уведомления» при открытии сам отмечает их прочитанными (`profiles.notifications_seen_at`) — после
  `/screens` у демо-пользователей колокольчик без счётчика. Других изменений в базе скрипт не делает.
- Если в базе нет ни одной заявки «Новая», снимок окна выбора подрядчика будет с ❌ (причина — в таблице).
- Скриншоты только на русском и только веб-версия.
