# Расход GitHub Actions в hey-helpy — замер и сокращение (11.11.2026)

Причина: 09.11.2026 GitHub заблокировал Actions во всём аккаунте Anton-Key («billing is currently locked»): хранилище Actions (0,5 ГБ на бесплатном плане) заполнено на 100 %, hey-helpy — $6,11 из $8,70 за ноябрь.

## 1. Замер (11.11.2026)

### Хранилище
| Что | Было | Стало |
|---|---|---|
| Artifacts (файлы сборок) | **6 файлов, 208,8 МБ** — все `hey-helpy-apk` (APK ~35 МБ каждый, от «Build Android APK», хранились 14 дней) | **2 файла, 70,4 МБ** (сборки 07.11; удалятся сами до 21.11) |
| Caches (кэши) | 3 кэша на `main`: Flutter SDK 1,6 ГБ, пакеты pub 71 МБ, bun 35 МБ (скриншот владельца, 11.11) — все используются (последний раз 3–4 дня назад). **В хранилище Actions (0,5 ГБ) не входят**: у кэшей свой лимит 10 ГБ на репозиторий ([GitHub Docs](https://docs.github.com/en/billing/concepts/product-billing/github-actions)) | не удалялись — пересоздались бы при следующем запуске |
| Releases (`latest-apk`, `latest-vps-apk`) | не трогали (в хранилище Actions не входят) | — |

Удалены 4 artifacts старше 7 дней: 30.10 (×2), 03.11 (×2) — 138,4 МБ.

## 2–5. Что изменено
| Workflow | Изменение |
|---|---|
| `build-apk.yml` | Автосборка — только при изменении `lib/`, `android/`, `assets/`, `pubspec.*`, `l10n.yaml` или самого файла (вручную — как раньше). `concurrency` с `cancel-in-progress: true`. Artifact APK хранится **3 дня** вместо 14 (нужен задаче `release` для `latest-apk` и для скачивания при ручном запуске). |
| `build-apk-vps.yml` | Только вручную (как было); artifact **3 дня** вместо 14; `concurrency` с отменой. |
| `deploy-web.yml` | Автовыкладка — только при изменении `lib/`, `web/`, `assets/`, `pubspec.*`, `l10n.yaml`, `site/`, `tools/site/`, `docs/demo/` или самого файла; artifact выкладки Pages — 1 день (явно). `concurrency` уже был. |
| `pr-check.yml` | Без изменений: уже есть `concurrency` с отменой. ⚠️ `paths` не добавлял — задача `check` может быть обязательной в защите `main`, и пропущенная проверка заблокировала бы слияние PR только с документами. |
| Кэши | Без изменений: `subosito/flutter-action` с `cache: true` строит ключ из версии Flutter (SDK) и хэша `pubspec.lock` (пакеты) — ключ не меняется на каждый коммит, все workflow делят один кэш на набор зависимостей. Gradle не кэшируется. |

Ожидаемо: APK и выкладка — только на коммитах с кодом приложения или сайта (коммиты с отчётами и документами — без сборки); хранилище APK — не больше 3 дней × число сборок (~35 МБ на сборку).

## 6. Проверка
- `actionlint 1.7.12` по изменённым файлам — 0 замечаний (до и после правок).
- Проверки PR сейчас не запустятся из-за блокировки — YAML проверен локально.

## Что сделать вам
1. **Снять блокировку:** причина — в аккаунте нет способа оплаты, а хранилище (0,5 ГБ на месяц, считается в ГБ-часах) уже израсходовано; без способа оплаты GitHub блокирует Actions до сброса 1-го числа. Добавить карту: https://github.com/settings/billing/payment_information. Бюджет Actions $20 уже стоит — больше не спишут; перерасход сейчас $0,01.
2. **Кэши не удалять** — в хранилище не входят и пересоздадутся.
3. **Слить PR** после снятия блокировки.

## Ограничения
- Минуты по задачам не измерены (API закрыт); минуты — по времени запусков. Удаление файлов не уменьшает уже накопленное за ноябрь хранилище — только будущее.
- Хранилище считается по всему аккаунту: другие репозитории не проверялись.
