## Как повторить проверку

```bash
node tools/site/build.mjs --out build/site && node tools/site/check.mjs build/site
node tools/site/serve.mjs build/site 8090 &
PLAYWRIGHT_BROWSERS_PATH=/opt/pw-browsers node tools/site/shots.mjs http://localhost:8090/   # 360 / 412 px + снимки
CHROME_PATH=/opt/pw-browsers/chromium-1248/chrome-linux64/chrome npx lighthouse@12 http://localhost:8090/ \
  --chrome-flags="--headless=new --no-sandbox" --view
npx html-validate@9 build/site/**/*.html
```
