## B. Группировка по городам (без миграции)

Город = часть адреса до первой запятой: `cityOf(address)` в `lib/features/directory/city.dart`
(одно место). Регистр не важен («москва» = «Москва»). Без адреса или без запятой — секция
«Без города» (в конце). Там же `objectDisplayName(object, {withCity})` — «Москва · Офис 3»,
`groupObjectsByCity` (города по алфавиту, внутри — по названию, «Офис 2» раньше «Офис 10»).
Тесты — `test/city_test.dart`.

«Город · Название» теперь везде, где объект показан без контекста города: таблетка фильтра,
карточка объекта на карте и подсказка маркера, строка заявки («Москва · Офис 3 · Лобби · Климат»),
карточка заявки, форма заявки (объекты по городам), голосовая заявка (место), выбор подрядчика,
отчёты (таблица заявок), помещения («Москва · Офис 3 · Лобби»), заголовок списка заявок объекта.
Внутри секций города — просто «Офис 3». Уведомления и «История» названия объекта не показывают —
там менять было нечего.

1. **Локации → «Список»**: секции «МОСКВА · 5», города по алфавиту, внутри — по названию.
2. **Локации → «Карта»**:
   - список слева / снизу — те же секции; в режиме «Объекты рядом» — по удалённости, с городом в названии;
   - над картой — чипы «Все · 37 · Абиджан · 2 · Белград · 16 · …» (число — открытые заявки
     города); нажатие плавно приближает карту к объектам города, «Все» — весь мир. Строка чипов
     прокручивается и гаснет у края (не уходит под кнопки карты);
   - мелкий масштаб (зум < 9): **один кружок на город** — сумма открытых заявок, кольцо — цвет
     самого тревожного объекта, под кружком подпись города. Если города на экране почти
     совпадают (весь мир на телефоне: Белград, Стамбул, Москва), они собираются в один кружок
     «Белград, Москва, Стамбул». Нажатие — приблизить. Крупнее — прежняя сетка;
   - минимальный зум карты — 1 (раньше 3), чтобы весь мир помещался.
3. **Фильтр «Объект»** (заявки): окно `ObjectPickerPanel` — секции по городам, первой строкой
   секции «Весь город» (галочка — выбран весь город, минус — часть; у городов из одного объекта
   строки нет), поиск по названию, городу и адресу. Подпись таблетки: «Москва · Офис 3»,
   «Москва (5)», «Москва · Офис 1 +2».
4. **Подрядчики**: под названием — «Москва · 5 объектов», «Белград · 7 объектов» (города —
   по числу объектов), у закреплённых «на всех объектах» — «Все объекты». В карточке — «Виды работ»
   и объекты по городам («МОСКВА · 2»), норма визитов по-прежнему меняется нажатием.
5. **Отчёты**: фильтр «Объект» — то же окно с городами и «Весь город», можно выбрать несколько
   объектов (`ReportQuery.objectIds`). Нормы визитов считаются по выбранным объектам.

## Ограничения и что не сделано
- Контакты подрядчиков (телефон, email) — нет полей в базе (нужна миграция 0014).
- Город берётся из адреса: если адрес записан без запятой («Москва Лесная 5»), объект попадёт
  в «Без города». Отдельное поле «город» — будущая миграция.

  оказавшихся рядом на экране, объединяются (подпись — список городов).
- Кластер с подписью города показывается и для одного объекта (Абиджан, Пекин) — чтобы на
  карте мира у всех городов были подписи.
