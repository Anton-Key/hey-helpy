Создай новую миграцию базы. Название: `$ARGUMENTS`

Если название не передано — спроси его и остановись.

## 1. Номер
- Посмотри файлы в `supabase/migrations/` (формат `NNNN_описание.sql`).
- Прочитай раздел «Миграции» и «База данных» в `CLAUDE.md`: там могут быть **занятые, но
  ещё не написанные** номера (например, «0008 — исправления безопасности (позже)»).
- Номер = больший из (максимальный номер файла, максимальный занятый номер в CLAUDE.md) + 1,
  четыре цифры с нулями.

## 2. Имя файла
`supabase/migrations/NNNN_<название>.sql`. Название — латиницей, `snake_case`, без пробелов;
если передано по-русски — переведи коротко на английский.

## 3. Содержимое
```sql
-- NNNN_<название>.sql
-- Назначение: <одно-два предложения по-русски, что и зачем меняет>
-- Зависит от: <номера миграций, на которые опирается>
-- Применяется вручную: Supabase → SQL Editor. Безопасно запускать повторно.

begin;

-- ... изменения ...

commit;
```
Правила (из CLAUDE.md): повторный запуск безопасен (`if not exists`, `create or replace`,
`drop ... if exists` перед `create policy`/`create trigger`); права — через RLS и триггеры;
у новых таблиц с данными компании — `enable row level security` и политики по `company_id`;
у `security definer` функций — `set search_path = public`; у каждой новой функции —
`revoke all ... from public, anon` и явный `grant execute ... to authenticated`, если её вызывает
приложение или политика (после 0008 новые функции по умолчанию закрыты для всех).

Если в запросе есть, что именно менять — напиши изменения. Если нет — оставь заготовку
и спроси, что должно быть внутри.

## 4. CLAUDE.md
Добавь строку в список миграций в разделе «База данных (Supabase)»:
`- **NNNN** — <назначение>.` и поправь фразу «следующая новая миграция — `…`» в разделе «Миграции».
Строку `Применённые миграции:` **не трогай** — её меняет только пользователь, когда применил.

## 5. НЕ применять
Не запускай SQL через Supabase MCP, `supabase db push` или как-либо ещё.

## 6. В конце
Напомни пользователю по-русски, пошагово:
1. Открыть Supabase → SQL Editor → New query.
2. Вставить содержимое файла `supabase/migrations/NNNN_….sql`, нажать Run.
3. Когда применится — дописать номер в строку `Применённые миграции:` в CLAUDE.md
   (после этого хук запретит менять файл).
