# Кадры для питча

17 кадров «Эй, Helpy» для слайдов демо-дня: телефон — 412 px (снимок ×2, чёткий на слайде), ПК — 1920 × 1080 с левым меню и служебными кнопками. Все данные — демо-компания «Демо БЦ» из рабочей базы, без пометок «ПРЕДПРОСМОТР»; планы этажей — нарисованные демо-схемы из хранилища.

Переснять: `cd tools/screens && PLAYWRIGHT_BROWSERS_PATH=/opt/pw-browsers node screens.mjs --pitch` — картинки перезаписываются, этот файл остаётся. Данные не меняются: голосовая заявка не отправляется, окна закрываются без сохранения.
