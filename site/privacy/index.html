Website privacy policy

Version of 23 October 2026. Applies to this website; the app is covered in the last section.

What the website collects

  • The website uses no cookies, visit counters, advertising or analytics services.
  • There are no forms that send data to a server. The “Request a demo” button opens Telegram — you decide what to write.
  • Fonts, images and video are loaded from the same address as the website, with no third-party services.

Hosting

The website is hosted on GitHub Pages. Like any web server, the host may keep technical request logs (e.g. IP address) under GitHub’s terms.

Demo requests in Telegram

If you message our bot @HeyHelpy_bot via the “Request a demo” link, we store your message text, your Telegram name and username, language and chat ID — only to reply and discuss a demo or pilot. Only the Hey Helpy team can see this data, and we do not share it with third parties. To have it deleted, send a request the same way — via the “Request a demo” link.

The app

Data processing in the Hey Helpy app (work orders, photos, location when checking in) is governed by the contract with the customer company. How data access works is described on the Security page.

The “AR labels” feature in the Android app uses “Google Play Services for AR” (ARCore) — a Google app on the phone, governed by the Google Privacy Policy. ARCore calculates the phone’s position on the phone itself; our code does not call Google services, and Google’s cloud anchors and geospatial positioning are switched off. The shot used to recognise equipment goes to our server and is not stored.
