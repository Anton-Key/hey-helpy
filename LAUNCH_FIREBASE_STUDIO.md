# Запуск Hey Helpy в Firebase Studio (для новичка)

Firebase Studio — это бесплатный редактор от Google, который работает **прямо в браузере**
и уже умеет собирать Flutter. Ничего ставить на компьютер не нужно.

Путь состоит из 3 частей:
1. Положить код проекта в GitHub (бесплатное «хранилище кода»).
2. Открыть этот код в Firebase Studio.
3. Вставить ключи Supabase и нажать «запустить».

База данных Supabase у тебя уже создана и настроена — её повторять не нужно.

---

## Часть 0. Забрать код к себе

1. Скачай из чата файл **`hey_helpy.zip`** (кнопка загрузки рядом с сообщением ассистента).
2. На компьютере найди скачанный `hey_helpy.zip`, нажми правой кнопкой → **«Извлечь всё»**
   (Extract All). Появится папка `hey_helpy` с файлами внутри.

---

## Часть 1. GitHub — положить код в интернет

1. Открой **github.com**, нажми **Sign up** и заведи бесплатный аккаунт (почта + пароль).
2. После входа справа вверху нажми **«+» → New repository** (новый репозиторий).
3. Repository name: `hey-helpy`. Оставь **Public**. Нажми **Create repository**.
4. На открывшейся странице найди ссылку **«uploading an existing file»**
   (или **Add file → Upload files**).
5. Открой на компьютере извлечённую папку `hey_helpy`, выдели **всё содержимое**
   (папки `lib`, `supabase`, файлы `pubspec.yaml` и т.д.) и **перетащи мышкой** в окно браузера.
6. Внизу нажми зелёную кнопку **Commit changes**. Код загружен. 🎉

---

## Часть 2. Firebase Studio — открыть проект

1. Открой **studio.firebase.google.com**, войди тем же Google-аккаунтом.
2. Нажми **Import** (или «Import repo» / «Open from GitHub»).
3. Вставь ссылку на свой репозиторий: `https://github.com/ТВОЙ_ЛОГИН/hey-helpy`
4. Firebase Studio откроет проект и сам начнёт подготовку (может занять пару минут:
   он скачивает нужные библиотеки — это как `flutter pub get`).

Если предложит «Enable Flutter/Dart» или установить расширения — соглашайся.

---

## Часть 3. Ключи Supabase и запуск

Ключи мы НЕ пишем в код — передаём при запуске.

1. Возьми ключи в Supabase: зайди в свой проект → **Project Settings → API**:
   - **Project URL** (вида `https://xxxx.supabase.co`)
   - **anon public** ключ (длинная строка).
2. В Firebase Studio открой встроенный **терминал** (меню сверху **Terminal → New Terminal**,
   внизу появится чёрное окно для команд).
3. Вставь туда команду (подставь свои значения вместо `<...>`):

   ```
   flutter run -d web-server --web-port 8080 \
     --dart-define=SUPABASE_URL=<твой Project URL> \
     --dart-define=SUPABASE_ANON_KEY=<твой anon key>
   ```

   Нажми Enter. Firebase Studio соберёт приложение и покажет **превью в браузере**
   (обычно справа откроется панель Web Preview).

4. Готово! Зарегистрируйся в приложении (email + пароль) — увидишь экран Hey Helpy.

---

## Сделать себя админом (после первого входа)

1. Зарегистрировался в приложении → в Supabase открой **Table Editor**.
2. В таблице `companies` нажми **Insert → Insert row**, впиши название компании, сохрани.
   Скопируй её `id`.
3. В таблице `profiles` найди свою строку, впиши в `company_id` тот `id`,
   а в `role` поставь `admin`. Сохрани.
3. Перезайди в приложении — увидишь всё как администратор.

---

## Если что-то пошло не так
- Красная ошибка в терминале — скопируй её текст и покажи ассистенту.
- Долго «крутится» — это нормально при первой сборке (несколько минут).
- Не видит ключи (экран «Не заданы ключи Supabase») — проверь, что команда запуска
  содержит оба `--dart-define` без опечаток.
