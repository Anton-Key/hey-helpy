# Сценарий показа «Эй, Helpy» на демо-дне

Живое демо — **2 минуты** внутри 5-минутного питча. Показываем на ноутбуке (ПК-версия, 1920 × 1080 или 1280 × 800), запасной вариант — видео `docs/demo/hey-helpy-demo.mp4` (тот же сценарий, 2:16) и телефон с APK.

Три «вау»-момента: **голос → ИИ разобрал заявку**, **волны на плане этажа**, **PDF-отчёт одним нажатием**.

Данные — рабочая база после миграций 0015 и 0016 (11 октября 2026), компания «Демо БЦ»:

| Что | Сколько (после Refresh demo) |
|---|---|
| Заявки | **91**: открытых 48, просрочено 11 |
| Объекты | **20 в 7 городах**, 5 регионов: Европа · 7 (Белград), СНГ · 5 (Москва), Ближний Восток · 4 (Дубай, Стамбул), Азия · 3 (Пекин, Шэньчжэнь), Африка · 1 (Абиджан) |
| Плановое ТО | **8 планов**; «Октябрь: выполнено 1 из 8» (принят «Проверка ИБП серверной»), группы «Не начато · 5», «В работе · 2» |
| Оборудование | 35 единиц, у «БЦ «Демо»» — 14 |
| Подрядчики | 12; у Huaxin FM — бригады «Пекин» и «Шэньчжэнь» |
| Отчёт за 30 дней | 79 заявок, 76 % в срок, 90 % приняты с первого раза, 81 % визитов в геозоне, плановое ТО 2 из 9 |

Числа сдвигаются с датой (просрочка, «30 дней») и после тестовых заявок — точные цифры смотреть в день показа.

## Подготовка за 30 минут до выхода

1. **Браузер — только Chrome или Edge.** В Яндекс Браузере, Opera, Firefox распознавания речи нет: там «Эй, Helpy» сразу откроет «Ввести текстом» с подсказкой (так и задумано, но голосового «вау» не будет).
2. **Свежие данные** — GitHub → Actions → **Refresh demo** → Run workflow (ветка `main`) → Review deployments → `production-db` → **Approve and deploy**. Ждать зелёную галочку (1–2 минуты). Ожидаемо в Summary: 91 заявка «Демо БЦ», до 16 визитов. Все тестовые заявки с прошлых показов удалятся. (Если тестовых заявок не создавали — можно пропустить: данные уже на месте.)
3. **Вход менеджером**: открыть сайт https://anton-key.github.io/hey-helpy/ (если публикация сайта ещё не включена — APK на телефоне или локальная сборка), войти демо-менеджером. На ПК в таблетке сверху — **«Демо БЦ · Администратор»** (после 0016 демо-менеджер — администратор компании).
4. **Очистить уведомления**: колокольчик → открыть список (отметятся прочитанными) → закрыть. Красного бейджа на колокольчике быть не должно.
5. **Проверить голос**: «Эй, Helpy» → сказать «проверка» → появляется текст → «Отмена». Разрешить микрофон «Всегда для этого сайта». Микрофон ноутбука, не наушники с Bluetooth (задержка).
6. **Проверить интернет**: голос и ИИ работают только онлайн. Если Wi-Fi площадки слабый — раздать интернет с телефона заранее.
7. **Открыть вкладки заранее** (в этом порядке):
   1. Сайт, вошли менеджером, вкладка «Главная» → «Заявки».
   2. Видео `hey-helpy-demo.mp4` (просто перетащить файл в окно браузера) — на паузе на первом кадре.
8. **Экран**: яркость на максимум, масштаб браузера 100 %, полноэкранный режим (F11). Закрыть лишние вкладки и панели закладок.
9. **Отключить уведомления ноутбука**: Windows — «Не беспокоить» (Win + A); macOS — «Фокусирование → Не беспокоить». Закрыть мессенджеры и почту. Выключить автообновления и заставку.
10. **Звук**: звук ноутбука выключить (не нужен), зарядка подключена.
11. **Телефон** (запасной): свежий APK по ссылке https://github.com/Anton-Key/hey-helpy/releases/download/latest-apk/hey-helpy.apk, вошли менеджером, режим «Не беспокоить».

## Сценарий (2 минуты)

| Время | Что нажать | Что сказать (1–2 фразы) |
|---|---|---|
| 0:00 | Экран «Главная» на ПК: список заявок (сегменты «Все · 91 / Открытые · 48 / Просрочено · 11»), левое меню | «Это рабочее место диспетчера здания. Все заявки офисов, отелей, складов — в одном месте, просроченное видно сразу.» |
| 0:10 | Большая зелёная кнопка **«Эй, Helpy»** слева → сказать в микрофон: *«В переговорной на третьем этаже не работает кондиционер, очень жарко»* → **«Готово»** | «Заявку не пишут — её говорят.» |
| 0:20 | ✨ **Вау 1.** Экран «Проверьте заявку» с пометкой **«Разобрано ИИ»**: заголовок, вид работ «Климат», помещение «Переговорная, 3 этаж», срочность «Высокий» | «ИИ за пару секунд разобрал речь: что сломалось, где, насколько срочно.» |

| 0:55 | Меню → **«Главная» → «Локации» → «Карта»** | «Один сервис на весь портфель: 20 объектов в 7 городах — Белград, Москва, Дубай, Стамбул, Абиджан, Китай. Цвет — по самой тревожной заявке.» |
| 1:10 | Меню → **«Плановое ТО»** (сверху «Октябрь: выполнено 1 из 8») | «Плановое обслуживание — по графику: задачи на месяц создаются сами, тут видно, сколько выполнено.» |
| 1:20 | Меню → **«Отчёты»** (блок «По регионам») → кнопка **печати** (принтер вверху) | «Контроль подрядчиков цифрами: визиты по геозоне, доля в срок, приёмка с первого раза — по каждому региону.» ✨ **Вау 3.** «И PDF для собственника — одним нажатием.» (окно печати браузера → «Отмена») |
| 1:40 | (Если есть время) Меню → **«Главная» → «Подрядчики» → Huaxin FM** → внизу **«Бригады» → «Пекин»** | «Доступ режется по месту и системе: бригада «Пекин» видит только пекинский офис. Ограничение делает база, а не интерфейс.» |
| 1:55 | Вернуться на «Главную» | «Приём, отправка, исполнение и контроль — заявку нельзя закрыть без фото и подтверждения.» |

**Если время поджимает** — пропустить плановое ТО и бригады: голос → ИИ → план → отчёт и PDF укладываются в 1:20.

⚠️ «Плановое ТО выполнено» в разделе «Плановое ТО» (1 из 8 — текущий период) и в «Отчётах» (2 из 9 — задачи, срок которых попал в последние 30 дней, включая сентябрьские) — разные числа, это нормально. Если спросят — «в плановом ТО — текущий месяц, в отчёте — выбранный период».

## Сценарий «Фото → единица → заявка» (40 секунд, шаг 22)

Подготовка: телефон (APK) или ноутбук с камерой; вошли **исполнителем** или менеджером; распечатанная картинка кондиционера `assets/demo_photos/ac_indoor.jpg` (или настоящий кондиционер на площадке — **не** снимать реальные объекты заказчиков). Нужны применённая 0017 (иначе работает, но без цифр в «Отчётах»), Refresh demo (имена «КД-301 / КД-302») и выложенная функция `photo-identify`.

| Время | Что нажать | Что сказать |
|---|---|---|
| 0:00 | Телефон: кнопка с **камерой** рядом с «+» (ПК: **«По фото»** в меню слева) | «Исполнитель стоит у оборудования и не знает, как оно называется в реестре.» |
| 0:05 | **«Где я»** → «Белград · БЦ «Демо»» → **«301 · Переговорная, 3 этаж»** (запомнится на следующий раз) | «Он в переговорной 301, третий этаж.» |
| 0:10 | **«Сфотографировать»** → снять кондиционер | — |
| 0:12 | ✨ **Вау.** «Смотрю на фото…» → **«Кондиционер, внутренний блок · Климат · 91%»**, «Подтёк воды под блоком», ниже **«Скорее всего: Кондиционер КД-301 · 301 Переговорная»** — «тот же вид · то же помещение» | «ИИ узнал, что это кондиционер, и сам нашёл, какой именно из реестра: в этой комнате ещё датчик дыма и огнетушитель, а на этаже — второй кондиционер, но подходит этот.» |
| 0:25 | **«Это он»** → окно «Новая заявка»: объект, помещение, оборудование «Кондиционер КД-301», вид работ «Климат», заголовок «Подтёк воды под блоком», «Снимок будет приложен к заявке» | «Заявка уже заполнена, фото приложено. Ничего не печатали.» |
| 0:35 | **«Создать»** | «Подрядчик назначен по закреплению — как у голосовой заявки.» |

**Если ИИ не ответил** («Не получилось распознать…») — **«Выбрать вручную»** → «Кондиционер КД-301» → дальше то же самое. «Даже без ИИ — два касания.»

Цифры к питчу — **«Отчёты»** → блок «Узнавание по фото: N снимков, угадано с первого раза X%, в среднем Y с» (появляется после первых узнаваний, нужна 0017).

## Если спросят — покажи

| Вопрос | Путь нажатий (ПК) | Что на экране |
|---|---|---|
| «А плановое обслуживание?» | Меню → **Плановое ТО** → «ТО кондиционеров» → «Текущий период: октябрь 2026» | План: объект «Москва · Офис 1», подрядчик МосКлимат, каждый месяц, чек-лист, история периодов. Задача периода — обычная заявка с меткой «Плановое ТО · октябрь 2026 · до 31 окт.» |
| «Как с несколькими странами?» | Меню → **Главная → Локации → Список** | Регион → страна с флагом → город: «Европа · 7 → Сербия → Белград», «СНГ · 5 → Россия → Москва» и т. д. |
| «Можно посмотреть только один регион?» | **Главная** → фильтр **«Объект»** → «Весь регион» под «Европа · 7» → «Применить» | Заявки только по региону; в «Отчётах» — фильтр **«Регион»** |
| «Где учёт оборудования?» | **Локации → Список → «БЦ «Демо»»** → раздел «Оборудование · 16» → **«Кондиционер серверной»** | Паспорт (Mitsubishi, инв. № КЛ-3-003, серийный), «Где стоит» (303 · Серверная, 3 этаж), «Показать на плане», планы обслуживания и заявки по этому оборудованию. Импорт из Excel / CSV — там же |
| «Кто что менял в правах?» | **Профиль → Моя компания → «Журнал изменений доступа»** (только администратор) | Журнал зон, бригад и ролей. Сейчас на рабочей базе изменений не было — «Изменений доступа пока не было»; строки появятся после первой смены роли или зоны |
| «А если менеджер отвечает только за Москву?» | **Профиль → Моя компания** → менеджер → **«Зона доступа»** (нужен второй менеджер в компании; сейчас его нет) — или показать бригаду «Пекин» (сценарий 1:40) | Правила «системы × места»: например, «Климат + Сантехника · Москва»; менеджер вне зоны ничего не видит — ни в списках, ни на карте, ни в отчётах |
| «Это работает на английском?» | Переключатель **RU / EN** в шапке справа | Work orders, PM (Preventive maintenance), Locations, Reports. Названия объектов и демо-заявок остаются на русском — это данные |

## Если что-то пошло не так

| Что случилось | Что делать (без паники, одна фраза залу) |
|---|---|
| Сайт не открывается / нет интернета | Переключиться на вкладку с **видео** → Play. «Покажу запись того же сценария.» |
| Вместо «Слушаю» сразу «Опишите заявку» и подсказка «Голосовой ввод работает в Chrome и Edge» | Открыт не тот браузер. Напечатать фразу → «Далее» — дальше тот же разбор ИИ. После показа — открыть в Chrome. |
| Микрофон не слышит / «Не получилось распознать» | Нажать **«Ввести текстом»** и напечатать ту же фразу → «Далее» — дальше тот же разбор и тот же экран. |
| Вместо «Разобрано ИИ» — «Разобрано по словарю» | Это нормально: ИИ не ответил за 10 секунд, сработал разбор на устройстве. Поля те же. «Даже без ИИ заявка разобрана.» |
| План этажа не загрузился (серый фон) | Нажать «Обновить» в шапке; не помогло — перейти к карте. |
| Карта без подложки | Маркеры и кластеры всё равно видны — продолжать. |
| PDF долго готовится | Сказать фразу про отчёт, не ждать — перейти к финалу. |
| Ноутбук завис | Телефон с APK: те же экраны, кнопка «Эй, Helpy» внизу. Или видео `hey-helpy-demo-phone.mp4`. |
