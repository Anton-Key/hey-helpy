# Сценарий показа «Эй, Helpy» на демо-дне

Живое демо — **2 минуты** внутри 5-минутного питча. Показываем на ноутбуке (ПК-версия, 1920 × 1080 или 1280 × 800), запасной вариант — видео `docs/demo/hey-helpy-demo.mp4` (тот же сценарий, 1:40) и телефон с APK.

Три «вау»-момента: **голос → ИИ разобрал заявку**, **волны на плане этажа**, **PDF-отчёт одним нажатием**.

---

## Подготовка за 30 минут до выхода

1. **Свежие данные** — GitHub → Actions → **Refresh demo** → Run workflow (ветка `main`) → Review deployments → `production-db` → **Approve and deploy**. Ждать зелёную галочку (1–2 минуты). Ожидаемо в Summary: 91 заявка «Демо БЦ», до 16 визитов. Все тестовые заявки с прошлых показов удалятся.
2. **Вход менеджером** (после миграции 0016 он администратор): открыть сайт https://anton-key.github.io/hey-helpy/ (если публикация сайта ещё не включена — APK на телефоне или локальная сборка), войти демо-менеджером. На ПК в таблетке сверху — «Демо БЦ · Администратор».
3. **Очистить уведомления**: колокольчик → открыть список (отметятся прочитанными) → закрыть. Красного бейджа на колокольчике быть не должно.
4. **Проверить голос**: «Эй, Helpy» → сказать «проверка» → появляется текст → «Отмена». Браузер — **Chrome или Edge** (в Яндекс Браузере, Opera, Firefox распознавание речи не работает). Разрешить микрофон «Всегда для этого сайта». Микрофон ноутбука, не наушники с Bluetooth (задержка).
5. **Проверить интернет**: голос и ИИ работают только онлайн. Если Wi-Fi площадки слабый — раздать интернет с телефона заранее.
6. **Открыть вкладки заранее** (в этом порядке):
   1. Сайт, вошли менеджером, вкладка «Главная» → «Заявки».
   2. Видео `hey-helpy-demo.mp4` (просто перетащить файл в окно браузера) — на паузе на первом кадре.
   3. (Если будет показ зоны доступа) вторая вкладка в **режиме инкогнито**, вошли «Менеджером Москва».
7. **Экран**: яркость на максимум, масштаб браузера 100 %, полноэкранный режим (F11). Закрыть лишние вкладки и панели закладок.
8. **Отключить уведомления ноутбука**: Windows — «Не беспокоить» (Win + A); macOS — «Фокусирование → Не беспокоить». Закрыть мессенджеры и почту. Выключить автообновления и заставку.
9. **Звук**: звук ноутбука выключить (не нужен), зарядка подключена.
10. **Телефон** (запасной): свежий APK по ссылке https://github.com/Anton-Key/hey-helpy/releases/download/latest-apk/hey-helpy.apk, вошли менеджером, режим «Не беспокоить».

## Сценарий (2 минуты)

| Время | Что нажать | Что сказать (1–2 фразы) |
|---|---|---|
| 0:00 | Экран «Главная» на ПК: список заявок, левое меню | «Это рабочее место диспетчера здания. Все заявки офисов, отелей, складов — в одном месте, просроченное видно сразу.» |
| 0:10 | Большая зелёная кнопка **«Эй, Helpy»** слева → сказать в микрофон: *«В переговорной на третьем этаже не работает кондиционер, очень жарко»* → **«Готово»** | «Заявку не пишут — её говорят.» |
| 0:20 | ✨ **Вау 1.** Экран «Проверьте заявку» с пометкой **«Разобрано ИИ»**: заголовок, вид работ «Климат», помещение «Переговорная, 3 этаж», срочность «Высокий» | «ИИ за пару секунд разобрал речь: что сломалось, где, насколько срочно.» |
| 0:30 | **«Отправить»** → открыть новую заявку в списке (сверху) | «Подрядчик назначен автоматически — по закреплённым за объектом видам работ. Никто не звонит и не пересылает.» (в карточке — «КлиматСервис») |
| 0:40 | В карточке заявки на оборудовании (например, «Течёт конденсат из кондиционера серверной») → **«Показать на плане»** | ✨ **Вау 2.** «Исполнитель сразу видит, где проблема: вот этаж, вот кондиционер — вокруг него волны.» |
| 0:55 | Меню → **«Главная» → «Локации» → «Карта»** | «Один сервис на весь портфель: Белград, Москва, Дубай, Стамбул, Абиджан, Китай. Цвет — по самой тревожной заявке.» |
| 1:10 | Меню → **«ППР»** | «Плановое обслуживание — по графику: задачи создаются сами, тут видно, сколько выполнено за месяц.» |
| 1:20 | Меню → **«Отчёты»** → кнопка **печати** (принтер вверху) | «Контроль подрядчиков цифрами: визиты по геозоне, доля в срок, приёмка с первого раза.» ✨ **Вау 3.** «И PDF для собственника — одним нажатием.» (окно печати браузера → «Отмена») |
| 1:40 | (Если есть второй менеджер) **«Профиль» → «Моя компания» → «Менеджер Москва» → «Зона доступа»** | «Каждому менеджеру — своя зона: этот видит только Москву и только климат с сантехникой. Ограничение делает база, а не интерфейс.» |
| 1:55 | Вернуться на «Главную» | «Приём, отправка, исполнение и контроль — заявку нельзя закрыть без фото и подтверждения.» |

**Если время поджимает** — пропустить ППР и зону доступа: голос → ИИ → план → отчёт и PDF укладываются в 1:20.

## Если что-то пошло не так

| Что случилось | Что делать (без паники, одна фраза залу) |
|---|---|
| Сайт не открывается / нет интернета | Переключиться на вкладку с **видео** → Play. «Покажу запись того же сценария.» |
| Микрофон не слышит / «Не получилось распознать» | Нажать **«Ввести текстом»** и напечатать ту же фразу → «Далее» — дальше тот же разбор и тот же экран. |
| Вместо «Разобрано ИИ» — «Разобрано по словарю» | Это нормально: ИИ не ответил за 10 секунд, сработал разбор на устройстве. Поля те же. «Даже без ИИ заявка разобрана.» |
| План этажа не загрузился (серый фон) | Нажать «Обновить» в шапке; не помогло — перейти к карте. |
| Карта без подложки | Маркеры и кластеры всё равно видны — продолжать. |
| PDF долго готовится | Сказать фразу про отчёт, не ждать — перейти к финалу. |
| Ноутбук завис | Телефон с APK: те же экраны, кнопка «Эй, Helpy» внизу. Или видео `hey-helpy-demo-phone.mp4`. |

## Запасное видео

- `docs/demo/hey-helpy-demo.mp4` — ПК 1920 × 1080, около 1:40, подписи внизу кадра на русском.
- `docs/demo/hey-helpy-demo-phone.mp4` — телефон 412 px, около 1:10.
- Данные — только демо («Демо БЦ»), планы этажей — нарисованные **ДЕМО-СХЕМЫ**.
- Как переснять: `bash tools/e2e/record_demo.sh` (локальная база, без интернета; описание — в начале файла `tools/e2e/record_demo.mjs`).
