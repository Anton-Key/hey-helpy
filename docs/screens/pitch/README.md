# Кадры для питча

29 кадров «Hey Helpy» для слайдов демо-дня (28 готовы; 29 — VPS-метки — снимает владелец с телефона): телефон — 412 px (снимок ×2, чёткий на слайде), ПК — 1920 × 1080 с левым меню и служебными кнопками. Данные — демо-компания «Demo Properties», без пометок «ПРЕДПРОСМОТР»; планы этажей — нарисованные демо-схемы.

Переснять: `cd tools/screens && PLAYWRIGHT_BROWSERS_PATH=/opt/pw-browsers node screens.mjs --pitch` (все кадры) или `… --pitch --only=17,21` (выбранные) — картинки перезаписываются, этот файл остаётся. Вход — демо-менеджер из `.env.demo`. Данные не меняются: голосовая заявка не отправляется, окна закрываются без сохранения.

Колонка «Откуда»: **рабочая** — рабочая база; **локальная** — локальная база (`tools/screens/local_pitch.mjs`); **макет** — HTML-макет; **шаг 27** — кадра ещё нет.

## Что переснять и почему

- **18, 21** — пересняты 15.10 (шаг 28) на **рабочей базе** после 0023 / 0024 и выкладки функций: `node screens.mjs --pitch --only=18,21`. Проверено глазами: в 18 нет подписи «В кадре не видно оборудования» — результат «Air conditioner, внутренний блок · Климат · 91 %» и «Скорее всего — Air conditioner AC-301»; в 21 — заявка «Water dripping from the AC» (назначена), «Плановое ТО до 31 окт.», «Последняя работа 5 окт. · ClimaService». Камера и ответ ИИ в Playwright — заглушки (живой камеры нет).
- **28** — HTML-макет (`tools/screens/tg_assign_mock.mjs`), тексты — из `supabase/functions/telegram-bot/texts.ts` (шаг 28: `assignNew`, `bTake`, `takeOk`).
- **29** — только с телефона владельца (VPS-APK, запись экрана); в Playwright нет ни ARCore, ни камеры.
- **17** — оставлен: второго менеджера в «Demo Properties» нет. Как завести менеджера «New York · Климат» и что нужно для пересъёмки — `docs/DEMO_SETUP.md`, раздел «Второй менеджер».
- **24** — локальная база: документ — это файл в хранилище, в демо-данных его нет (его прикрепляют в приложении).
- **22** — HTML-макет: тексты как у бота (`supabase/functions/telegram-bot/texts.ts`), фото «после» — нарисованная картинка `assets/demo_photos/ac_after.jpg`, номер заявки условный, без логотипов Telegram.
